# Versione 1.0.1

Revisione della traduzione italiana per il gioco aggiornato.

## Compatibilità

`resources.assets` ricostruito e validato tecnicamente sulla build Steam
**25907859**, con il font personalizzato e gli accenti conservati.
Per la precedente build **22682990** rimane disponibile la release v1.0.0.

## Novità principali

- Migliorati naturalezza, fedeltà, referenti e coerenza dei testi: 363 righe e
  364 campi modificati in 18 dei 20 file rispetto alla v1.0.0.
- Adattate le indicazioni su telescopi e cartografi e i codici documentali alla
  nuova fonte inglese.
- Riparati i marcatori individuati e chiariti i cinque precedenti casi di
  fonti mancanti o differenze di versione.
- Inseriti tutti i testi in UTF-8 per mantenere gli accenti anche nel diario.
- Aggiornato lo script facoltativo di ricostruzione degli asset.

Dettagli nel [changelog](https://github.com/lorenfa99/dread-delusion-italiano/blob/v1.0.1/CHANGELOG.md).

## Installazione

Chiudi il gioco. Conserva una copia dell'originale e sostituisci `resources.assets` in:

`Dread Delusion\windows_content\Dread Delusion_Data`

Non occorre eseguire script o modificare i TXT. Un aggiornamento del gioco può
ripristinare il file originale; usa l'asset solo sulla build indicata.
