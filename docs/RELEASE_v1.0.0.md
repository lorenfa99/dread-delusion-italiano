# Versione 1.0.0

Prima release pubblica della traduzione italiana completa.

## Compatibilità

Verificata sulla versione Steam con build ID **22682990**.

## Installazione rapida

Scarica `resources.assets`, conserva una copia dell’omonimo file originale e sostituiscilo in:

`Dread Delusion\windows_content\Dread Delusion_Data`

Un aggiornamento del gioco può ripristinare il file originale.
